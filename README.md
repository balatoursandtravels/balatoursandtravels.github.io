# Bala Tours & Travels

Editable reference-style taxi/tour website.

## Hero highlights
The old numeric stats (50+ fleet, 13.8k+ guests, 1000+ reviews) have been removed and replaced with six productive service highlights.

## Booking form
Pickup and Drop are searchable and the form contains a vehicle and date selector.

When the visitor clicks **FIND RIDE**, the site now validates Pickup, Drop and Date, then shows a visible **Your Trip** result card with:
- route
- date
- selected vehicle
- Bala Tours & Travels
- an **ENQUIRE ON WHATSAPP** button

The button opens WhatsApp with the complete trip details.

## Edit
Open `config.js` in Notepad and change business details, services, fleet, destinations, temples, statistics, and the location list.

## Test
Double-click `index.html` to open the site in your browser.

## Publish free
Upload the files to a public GitHub repository. Then:
Settings -> Pages -> Deploy from a branch -> `main` -> `/ (root)` -> Save.


## Images
The final version includes locally stored image assets for the hero, about section, vehicles, and destination/temple cards. Replace files in `images/` with your own licensed photos any time.

## Hero banner
The supplied user banner is used as the website hero banner at `images/hero-banner.png`.
